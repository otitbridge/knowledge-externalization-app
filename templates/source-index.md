# 一次資料索引テンプレート

原本の内容を変更せず位置と版を管理する。SRC-IDごとに以下を記入する。

## {{SRC-ID}}

- 原本パス: {{source/records/ 内の相対パス}}
- 原本位置: {{見出し・行範囲／ページ・段落／音声の時間範囲}}
- 話者・作成者: {{識別子}}
- 役割: {{確認できた役割。未確認なら明記}}
- 資料種別: {{対話／回答／観察／文書}}
- 取得日: {{日付}}
- 原本Gitコミット: {{完全なコミットID、草稿段階では未コミット}}
- 原本SHA-256: {{生バイトのSHA-256}}
- ハッシュ方式: raw-bytes
- 訂正・追加対象: {{旧SRC-ID。該当なしならその旨}}
- 関連Q: {{Q-ID。なければなし}}

確認者の役割と回答の位置付けは推測しない。索引への登録は専門家レビューや利用承認ではない。
