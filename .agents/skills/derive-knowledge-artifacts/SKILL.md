# 正本からの派生作成

AGENTS.mdと [知識の書式](../../../docs/knowledge-format.md) のMermaid・一覧・教材規則を読む。意味情報源は指定された正本に限定する。一次資料から正本を飛ばして作成しない。

1. 入力正本の文書ID・版・対象ID・状態、関連Q、出力用途を確認する。未レビューでもレビュー用資料は作成できる。正式指示は当該版・経路・用途の承認が確認できる場合だけ。
2. 手順がある場合はフロー、独立した知識は一覧など、既存の関係を忠実に表せる形式を選ぶ。見栄えのための接続や正常終了ノードを作らない。
3. フローの場合は正本IDからハイフンだけを除く。表示名・条件を転記し、.mmdと同じ本文を埋め込んだ表示用.mdを作成する。未レビュー状態を文字でも表示し、関係IDとの対応表を付ける。
4. 教材は説明・正答・フィードバックを正本IDに対応付ける。根拠のない誤答、原因、対策、数値を追加しない。根拠内で設問化できなければ知識一覧または記述式とする。
5. [派生物管理票](../../../templates/artifact-record.md)に入力版・ハッシュ・対象ID・生成方法を記録する。部分出力は省略範囲を明示し、経路をつなぎ替えない。
6. [検証チェックリスト](../../../docs/validation-checklist.md)で正本と出力を照合する。図の表示確認ができなければ未実施と記録する。PNGなど追加形式が必要なら、利用可能な変換手段と依存を確認してから作成する。

派生物の意味変更を求められたら該当正本IDを確認し、根拠を確認して正本を更新してから再生成する。レイアウトのみの変更では意味の一致を検査する。ファイル名を変える場合は図の2形式・リンク・管理票も同期する。

完了時は、成果物、入力版、用途と状態、検査結果、未実施事項を報告する。生成しただけでレビュー済み・承認済みとは扱わない。
