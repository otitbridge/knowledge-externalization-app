# 回答とレビューの反映

AGENTS.md、[知識の書式](../../../docs/knowledge-format.md)、対象正本、確認票、導入設定を読む。[レビュー記録](../../../templates/review-record.md)と[確認事項](../../../templates/questions.md)のテンプレートを使用する。

1. 回答・判断の原文、回答者と役割、対象版とID、確認範囲を特定する。回答の受領と承認は区別する。役割や対象が不明ならその部分をQにし、状態昇格を保留する。
2. 原文を新しい一次資料に保存してSRC-IDを付ける。既存原文を訂正せず、旧SRC-ID・Q-IDへ対応付ける。既に保存済みなら重複登録せず参照する。
3. 資料に明示された回答だけを正本へ反映する。部分回答の残りはQに残す。closedにする場合は理由・根拠・反映版を記録し、履歴を消さない。
4. 専門家の確認はexpert-reviewed、利用責任者の明示的な利用承認はapprovedへ対応付ける。対象版・ID・用途が一致する範囲だけを変更し、記録へリンクする。AI検査や一般のユーザー回答を代用しない。
5. 内容・条件・関係の変更があれば、変更箇所と依存範囲を再レビューへ戻す。旧版に対する承認を新しい本文へ引き継がない。確認後に状態・記録参照だけを更新した場合はその事実を記録する。
6. 正本・確認票・索引・レビュー記録・対応派生物を整合させ、[検証チェックリスト](../../../docs/validation-checklist.md)を実施する。

専門家へ質問する文案は作成できるが、外部への送信はこのSkillの権限に含めない。回答がない部分について、専門家の判断や承認を代行しない。

完了時は、反映した回答、変更した状態とその根拠、残る質問、利用承認の範囲、検査結果を報告する。
